# 🎵 Singer2Singer - 挑战从一个歌手到另一个歌手

> 用图论找到两个歌手之间的最短连接路径

**在线体验**: [http://singer2singer.akie0126.xyz/](http://singer2singer.akie0126.xyz/)

## 📌 项目介绍

这是一个基于网易云音乐的有趣挑战网站。你可以输入任意两个歌手名字，系统会自动找出他们之间的**最短合作路径**。

例如：吴京 → ... → 林俊杰 只需几步连接。

### 核心原理

将网易云音乐建模为一个**无向图**：
- **节点** = 歌手
- **边** = 合作歌曲（共同出现在一首歌中）

然后用经典的 **BFS（广度优先搜索）** 算法找最短路径，这就是著名的**六度分隔理论**的实践。

## 📦 部署指南

### 前置要求

1. **部署 Netease API**

首先部署网易云音乐 API 服务：

```bash
git clone https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced.git
cd api-enhanced
# 按照该项目的说明部署（默认运行在 localhost:3000）
```

2. **安装依赖**

```bash
pip install flask waitress requests
```

### 启动服务

```bash
python app.py
```

服务将运行在 `http://0.0.0.0:12315`

### 项目文件说明

| 文件 | 说明 |
|------|------|
| `main_moreworker.py` | 核心搜索引擎，包含 BFS 算法和缓存机制 |
| `app.py` | Flask 后端，处理 HTTP 请求和流式响应 |
| `templates/index.html` | 前端页面，实时展示搜索进度 |

## 🎮 使用示例

1. 打开网站
2. 输入开始歌手名（如：*吴京*）
3. 输入结束歌手名（如：*林俊杰*）
4. 点击"探索"开始搜索
5. 实时查看搜索进度和最终路径

## ⚙️ 配置参数

在 `main_moreworker.py` 中可调整：

```python
BASE_URL = "http://localhost:3000"  # API 服务地址
MAX_DEPTH = 10                      # 最大搜索深度
PAGE_LIMIT = 100                    # 每页歌曲数
TIMEOUT = 15                        # 请求超时（秒）
MAX_SONGS_PER_ARTIST = 400          # 每个歌手最多抓取歌曲数
MAX_WORKERS = 1                     # 并发线程数
```

## ⚠️ 性能说明

- 自有服务器性能有限，**随时可能因资源不足而出现延迟或崩溃**
- 搜索时间取决于两个歌手的"音乐距离"
  - 热门歌手（如吴京、林俊杰）：秒级完成
  - 冷门歌手或跨风格：可能需要 10分钟以上
  - 完全孤立的歌手：可能无法连接

## 🔍 算法复杂度

- **时间复杂度**: O(V + E)，其中 V 是歌手数，E 是合作关系数
- **实际瓶颈**: I/O 操作（网络请求），而非计算

## 🎯 有趣的发现

这个项目验证了**六度分隔理论**——在网易云音乐的世界里，几乎所有歌手都能在 6-10 步内相互连接，充分体现了音乐世界的互联性。
